2. Database Validation

The project database is db/nifty100.db. The implemented database layer contains core tables for companies, sectors, financial statements, market data, ratios, peer analysis, documents and pros/cons signals.

  • 92 companies are represented in the project database.
  • Financial-ratio processing produced 1,160 ratio rows during the project validation cycle.
  • Two companies, ATGL and SBIN, were identified during QA as missing ratio records and were treated as explicit data-quality exceptions rather than silently fabricated.
