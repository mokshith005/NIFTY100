\# NIFTY 100 Data Dictionary



\## Overview



This data dictionary describes the processed datasets and SQLite database used in the NIFTY 100 Data Foundation project.



The project contains 12 database tables sourced from 12 Excel files:



1\. companies

2\. profitandloss

3\. balancesheet

4\. cashflow

5\. documents

6\. analysis

7\. prosandcons

8\. financial\_ratios

9\. market\_cap

10\. peer\_groups

11\. sectors

12\. stock\_prices



All company-level datasets use `company\_id` as a foreign-key reference to `companies.id`.



\---



\## 1. companies



Master table containing company identification, profile and valuation-related information.



| Column | Type | Description |

|---|---|---|

| id | TEXT | Unique company/ticker identifier. Primary key. |

| company\_logo | TEXT | URL or reference to the company logo. |

| company\_name | TEXT | Official/company display name. |

| chart\_link | TEXT | Link/reference to company chart data. |

| about\_company | TEXT | Company description/profile information. |

| website | TEXT | Company website URL. |

| nse\_profile | TEXT | NSE company profile URL/reference. |

| bse\_profile | TEXT | BSE company profile URL/reference. |

| face\_value | REAL | Face value per share. |

| book\_value | REAL | Book value per share/company book value metric. |

| roce\_percentage | REAL | Return on Capital Employed percentage. |

| roe\_percentage | REAL | Return on Equity percentage. |



\*\*Primary Key:\*\* `id`

\## 2. profitandloss



Historical profit and loss statement data by company and year.



| Column | Type | Description |

|---|---|---|

| id | INTEGER | Unique record identifier. Primary key. |

| company\_id | TEXT | Company identifier referencing `companies.id`. |

| year | TEXT | Financial year. |

| sales | REAL | Revenue/sales generated by the company. |

| expenses | REAL | Total operating and related expenses. |

| operating\_profit | REAL | Profit generated from operating activities. |

| opm\_percentage | REAL | Operating Profit Margin percentage. |

| other\_income | REAL | Income other than operating revenue. |

| interest | REAL | Interest expense. |

| depreciation | REAL | Depreciation expense. |

| profit\_before\_tax | REAL | Profit before tax. |

| tax\_percentage | REAL | Tax rate/percentage. |

| net\_profit | REAL | Profit after tax. |

| eps | REAL | Earnings per share. |

| dividend\_payout | REAL | Dividend payout percentage/metric. |



\*\*Foreign Key:\*\* `company\_id → companies.id`



\*\*Index:\*\* `company\_id, year`
